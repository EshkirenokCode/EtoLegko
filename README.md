# Скорость скачивания по HTTP

Нужен Python 3.8 или новее. Устанавливать пакеты не нужно.

```sh
python3 speed_test.py 'https://example.com/large-image.jpg'
```

Замените URL в примере на прямую ссылку на большой файл. Скрипт скачает его 10 раз подряд. Каждый запрос начинается после того, как скрипт дочитает предыдущий ответ. Файл на диск не записывается.

## Как считается скорость

Время запроса считают от отправки до конца чтения ответа. Ожидание сервера и переходы по редиректам входят в замер. Скрипт выводит среднее время в секундах и общий размер скачанных тел ответов в байтах.

Скорость в Мбит/с равна общему объёму в байтах, умноженному на 8 и поделённому на суммарное время в секундах и на миллион.

Если запрос завершится ошибкой, скрипт выведет его номер и завершится с кодом 1. Тайм-аут на сетевую операцию составляет 30 секунд.
